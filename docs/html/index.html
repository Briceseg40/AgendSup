AgendSup Documentation

Introduction

Bienvenue dans la documentation d'AgendSup, une application web de gestion d'agenda pour le BUT Informatique. Cette application permet aux étudiants de gérer leurs cours, leurs devoirs, de rejoindre ou créer des classes, et de consulter un agenda collaboratif.

Dépôt GitHub

Le code du projet AgendSup est disponible sur ce dépôt GitHub. Vous y trouverez les instructions nécessaires pour installer l'application sur votre machine.

Fonctionnalités principales

  • Gestion des classes
  • Consultation de l'agenda
  • Ajout et suivi des devoirs
  • Gestion des utilisateurs (inscription, connexion, mot de passe oublié)

Fonctionnalités principales

  • Les devoirs sont gérer et poster par les Étudiants qui ont le rôle de délégué seuls eux peuvent ajouter les devoirs.
  • Les cours de révisions sont quant à eux poster par les Étudiants ayant le statut "Étudiant Ressource".
  • Tous les étudiants peuvent consulter les devoirs ainsi que créer ou rejoindre une salle de classe.

Conventions de Nommage

Les conventions suivantes sont utilisées dans le code source du projet AgendSup :

Classes et Types

Basé sur le style Camel Case pour les classes, en commençant par une majuscule.

Exemples :

  • ControllerClasse
  • ClasseDAO

Méthodes

Les méthodes utilisent le style camelCase en commençant par une minuscule.

Exemples :

  • lister()
  • render()

Variables

Les variables utilisent le style snake_case.

Exemples :

  • $id_cours
  • $devoir

Installation

Pour générer la documentation sur votre machine :

  1. Installer Doxygen (https://www.doxygen.nl/)
  2. Placer ce fichier mainpage.dox dans le dossier docs/
  3. Ajouter docs/mainpage.dox au champ INPUT dans le fichier Doxyfile :
    INPUT = . ./docs/mainpage.dox
  4. Exécuter la commande :
    doxygen Doxyfile

Utilisation de la documentation

La documentation générée inclura :

  • La liste des classes et méthodes
  • Les fichiers et templates Twig
  • Les diagrammes et relations entre classes (si Graphviz est configuré)
