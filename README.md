# AgendSup
## Présentation
**AgendSup**, le site, vous permettra de pouvoir accéder à vos devoirs grâce à sa section agenda où vous pourrez consulter, si vous êtes un étudiant, ou ajouter des devoirs si vous êtes étudiant délégué ou bien proposer des horaires de révision si vous êtes étudiant ressources.

# Fonctionnalités Clés
- **Consultation** des devoirs en temps réel.
- **Rôles différenciés** entre les étudiants, étudiants délégués et les étudiants ressources.
- **Planification de révisions** grâce a un espace dédié pour organiser l'entraide.
